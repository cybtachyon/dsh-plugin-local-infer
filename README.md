# dsh-plugin-local-infer

A DeepSeek Harness plugin for local inference. It sizes local engines (llama.cpp, NInfer, Hyper-Qwen, Strata) to your hardware, launches them, and publishes a local engine as a DSH model.

## Install

Command line:

```bash
dsh plugin --profile web add https://github.com/cybtachyon/dsh-plugin-local-infer
```

Web UI: click **Plugins** ➡️ **Add Plugin** ➡️ paste `https://github.com/cybtachyon/dsh-plugin-local-infer`.
